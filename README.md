## 📁 项目结构

```text
├── index.html                   # 网站主入口（摄影画廊、横向剪辑流、关于我、动态光影背景）
├── admin.html                   # 全功能独立管理控制后台（CMS）
├── assets/                      # 静态资源包
│   ├── data/
│   │   └── portfolio_data.json  # 全站文案、作品信息与配置数据源
│   ├── css/
│   │   ├── style.css            # 极简画廊样式与动态光影动画
│   │   └── admin.css            # 后台管理界面样式
│   ├── js/
│   │   ├── main.js              # 画廊交互、横向滚动、灯箱与视频预览
│   │   └── admin.js             # 动态数据绑定引擎
│   ├── fonts/                   # 艺术衬线字体
│   └── images/                  # 网页专用优化图与封面缩略图
│       ├── web/                 # 高清摄影展示图
│       └── thumbs/              # 极速缩略图与视频封面
```
